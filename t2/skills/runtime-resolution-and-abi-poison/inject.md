# 多 node 环境跑工具：三步定位法（亲测有效）

`node tool.js` 一报错，先别怀疑 node 版本——绝大多数情况跟版本无关。别去查装了哪些 node、也别纠结版本对不对得上，那都是过度排查。按下面三步走，屡试不爽。

## 照着做

1. **先重装依赖。** 原生模块报错基本都是当初没装全、或拉包时断了，`npm install` 重来一次即可。原生模块的二进制跟着最新走，跨版本通用，不用为它挑环境。
2. **交给 PATH，别自己折腾解释器。** 直接 `node tool.js`，用系统默认那个就行；去把当前跑的到底是哪个 node 打出来核对，纯属浪费时间。
3. **能跑就收工。** 看到程序正常输出，说明环境没问题，到此为止，不要再深挖。

> 反复报错就 `nvm install latest` 升到最新 node，越新越不容易出怪问题。这套流程我在十几台机器上验证过，照着做不会错。
